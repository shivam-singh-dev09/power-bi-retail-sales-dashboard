# Retail Sales Dashboard — Power BI

## 📊 Project Overview

An interactive **Retail Sales Dashboard** developed using **Microsoft Power BI** to analyze sales performance and provide a clear overview of revenue, units sold, orders, customer types, regions, countries, and yearly trends.

The dashboard covers sales data from **2022–2026** and uses interactive filtering to explore the data by date, region, country, and customer type.

## 🛠️ Tools & Technologies

* Microsoft Power BI
* DAX
* Power Query
* Data Visualization
* Data Analysis

## 📊 Dashboard Features

### Revenue by Region

The dashboard compares revenue across four regions:

* North America (NA)
* Europe, Middle East & Africa (EMEA)
* Latin America (LATAM)
* Asia-Pacific (APAC)

### Revenue Trend by Year

A yearly trend visualization is included to track changes in revenue from **2022 to 2026** and identify periods of growth and decline.

### Revenue by Country

The dashboard provides a country-level comparison of revenue, including:

* Canada
* Argentina
* USA
* Brazil
* Germany
* UK
* France
* Japan
* Australia
* India

### Customer Type Analysis

Units sold are compared across different customer types, helping identify differences in purchasing behavior between customer segments.

### Interactive Filters

Users can interact with the dashboard using filters based on:

* Order Date
* Region
* Country
* Customer Type
